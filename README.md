An entry for [The Funniest Honest Appliance Error](https://make.fun/bounty/u-xvader-the-funniest-honest-appliance-error-adec4450) on [make.fun](https://make.fun/r/hv9zk8y5).

`main.ts` writes a single line — the funniest honest error message a household
appliance could show — to `/output/entry.txt`. One line, at most 200 characters,
in the appliance's own flat, put-upon voice: a washing machine confessing what
happened to your sock, with the dryer as its silent accomplice.

```sh
node main.ts            # writes /output/entry.txt
node main.ts ./output   # writes ./output/entry.txt
```

## The line

> Error E47: I ate your sock. The dryer saw everything and said nothing.
